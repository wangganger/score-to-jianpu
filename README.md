# score-to-jianpu

用于 Codex 的五线谱转简谱、逐音复核、独立声部与 A4 打印排版技能。

它保留原谱的音高体系、时值和连线，要求每位演奏者的谱行完整标出音符与休止。声部分配不明、原谱缺拍、删音或补休止都需明确处理，不能用拍数检查通过代替正确性证明。

## 使用

将本仓库目录放到 Codex 的技能目录下，文件夹名为 `score-to-jianpu`。通常为 `~/.codex/skills/score-to-jianpu`；自定义环境使用对应的技能目录。重新加载技能后可调用：

> 请用 $score-to-jianpu 将这些五线谱转成独立声部简谱，核对音高、时值和连线，制作 A4 竖向打印版。

详见 [SKILL.md](SKILL.md)。技能自动发现默认开启。

## 本地验证

Python 3.10 或更高版本，无第三方包依赖：

```sh
python scripts/validate_score.py assets/example-score.json
python -m unittest discover -s scripts -p "test_*.py" -v
```

校验范围包括有理数拍数、单音声部中的错误和弦、明确的休止、声部对齐、延音线端点、连音组和可选简谱音高映射。退出码 0 只表示这些数据检查通过，不代表已正确识读原图或通过人工音乐校对。

曲谱 PDF 的生成需要当前环境可用的矢量制谱/PDF 工具、可用字体和页面渲染器；本仓库提供流程及数据校验器，不包含通用自动识谱引擎或通用制谱器。

本仓库不包含用户上传的谱图、完整歌曲编配、生成曲谱、个人绝对路径或私有字体。示例仅为测试用新写片段。
